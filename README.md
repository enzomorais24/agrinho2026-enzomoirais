# AgroFuturo 🌱

Site informativo sobre agricultura familiar no Brasil, com foco no Paraná e no impacto dos pequenos produtores na economia das cidades pequenas.

## Sobre

O AgroFuturo apresenta dados reais, mapas interativos e conteúdo educativo para mostrar como 4,3 milhões de agricultores familiares sustentam comunidades inteiras — do campo à mesa.

## Funcionalidades

- Loading screen com barra de progresso
- Skeleton loading nos cards de conteúdo
- Header flutuante com transição suave ao rolar
- Contadores animados com dados do IBGE
- Seção "Um Dia no Campo" — rotina do produtor
- Cards "Sabia que?" com fatos reais
- Comparativo visual: cidade com vs sem agro familiar
- Seção de desafios do campo
- Mapa interativo do Brasil por regiões
- Mapa do Paraná com accordion por região
- Quiz de 5 perguntas com resultado
- Modo dark/light com persistência
- Scroll indicator lateral
- Página Sobre com fontes e créditos
- Transição de página suave
- Responsivo para mobile

## Tecnologias

- HTML5
- CSS3
- JavaScript (vanilla)

## Fontes dos dados

- IBGE — Censo Agropecuário 2017
